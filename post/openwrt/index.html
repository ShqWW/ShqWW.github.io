OpenWrt安装与设置

软路由系统OpenWrt安装与基本设置，基于25.12的x86版本。

1.下载与安装

下载

首先从OpenWrt 25.12的x86版本官方下载地址下载系统压缩包文件到本地电脑并解压得到img文件。 其他辅助工具：雷电PE等引导系统(思路和给普通PC装操作系统类似，这里不再赘述)； 镜像烧录工具DiskImage

安装

给x86软路由接入显示器和鼠标键盘。在软路由硬件上通过引导U盘进入雷电PE引导系统（可以用其他引导代替），把软路由系统硬盘所有分区删除后，配合镜像烧录工具将img文件写入到软路由系统硬盘中。退出雷电PE后拔出U盘，重启软路由硬件，若成功进入OpenWrt系统，则说明安装成功。

2.基本设置

不要拔出显示器和鼠标键盘，进入OpenWrt系统后，先设置网络接口。使用命令vim /etc/config/network编辑网络配置文件，把eth0设置为WAN口，把eth1、eth2、eth3等其他接口设置为LAN口（视网络实际接口而定）。同时把软路由本机IP地址设置为192.168.100.0。

...
config interface 'lan'
        option device 'br-lan'
        option proto 'static'
        list ipaddr '192.168.100.0/24'
...
config device
        option name 'br-lan'
        option type 'bridge'
        list ports 'eth1'
        list ports 'eth2'
        list ports 'eth3'
...
config interface 'wan'
    option device 'eth0'
...
config interface 'wan6'
    option device 'eth0'
...

修改好后保存退出vim，然后可以关机并拔出显示器和鼠标键盘。接好局域网线路之后重启，使用另一台电脑连接到软路由的LAN口(也可以通过Wi-FiAP连接到软路由), 使用ssh访问ssh root@192.168.100.0,或浏览器地址栏输入http://192.168.100.0/cgi-bin/luci/访问OpenWrt的Web管理界面。如果成功访问，则说明网络接口设置成功。

初次访问Web管理界面时，系统会提示设置密码，设置好后保存即可。之后可以在Web管理界面中进行更多的设置和安装软件包。

3.联网设置

互联网设置主要是设置WAN口的上网方式，这里以PPPoE拨号为例。进入Web管理界面，点击“Network”->“Interfaces”，编辑WAN口设置（注意不是Wan6），默认是DHCP方式，改为PPPoE方式，输入运营商提供的账号和密码，保存并应用。如果成功获取到IP地址，则说明拨号成功。如果连接软路由的设备能访问互联网，则说明软路由的互联网设置成功。如果仅仅需要最基础的上网功能，到这步就可以了。

4.必要软件包安装

OpenWrt25.12默认使用APK包管理器，成功连接互联网后，需要下载一些常用软件包完成后续高级设置。使用ssh访问软路由，通过命令行下载安装基础软件包。

apk update
apk del dnsmasq
apk add dnsmasq-full
apk add openssh-sftp-server

5.硬盘扩容 （仅限ext4文件系统）

方案1–新建分区再挂载

OpenWrt由于是直接烧录到硬盘的，所以默认只会占用硬盘的一小部分空间，剩余空间需要手动扩容。使用ssh访问软路由， 首先安装必要的软件包：

apk add fdisk block-mount

通过命令行进行硬盘扩容。首先查看硬盘分区情况：

fdisk -l

记录下硬盘名称比如/dev/nvme0n1，然后使用fdisk工具进行分区修改：

fdisk /dev/nvme0n1

按照提示输入p查看分区表，记录下分区号和起始扇区。然后按n创建新分区，输入分区号，起始扇区号尽量按提示最小的输入，结束扇区号按提示最大输入。然后按w保存退出。

这里假设新建分区是/dev/nvme0n1p3，格式化新分区为ext4文件系统。

mkfs.ext4 /dev/nvme0n1p3

进入Web管理界面，点击System->Mount Points，在Mount Points一栏下添加挂载点，选择新建分区uuid并映射到根目录\，然后点击保存。别忘了最后在页面底部点击Save & Apply保存应用设置。系统会提示需要运行某些命令。

最后再进入ssh命令行执行（/dev/nvme0n1p3可能需要修改）：

mkdir -p /tmp/introot
mkdir -p /tmp/extroot
mount --bind / /tmp/introot
mount /dev/nvme0n1p3 /tmp/extroot
tar -C /tmp/introot -cvf - . | tar -C /tmp/extroot -xf -
umount /tmp/introot
umount /tmp/extroot

重启系统后完成硬盘扩容。通过Status->Overview可以查看硬盘使用情况，若显示Disk space的大小已经变为新分区大小，则说明扩容成功。 最后卸载软件包：

apk del fdisk block-mount

方案2–扩展已有分区并调整文件系统大小(推荐)

首先安装必要的软件包：

apk add losetup resize2fs parted

列出硬盘分区情况：

parted -l

若提示执行Fix，则选择执行Fix操作。 假设硬盘名为/dev/nvme0n1，则扩容分区到整个硬盘：

parted /dev/nvme0n1 --script resizepart 2 100%

循环挂载分区2（假定扩容分区号为2）：

losetup /dev/loop0 /dev/nvme0n1p2

再执行：

e2fsck -f /dev/loop0

最后调整文件系统大小：

resize2fs -f /dev/loop0

重启系统后完成硬盘扩容。通过Status->Overview可以查看硬盘使用情况，若显示Disk space的大小已经变为新分区大小，则说明扩容成功。

6.VPN安装

这里以OpenClash为例，直接通过命令行运行以下命令：

apk update
apk add bash iptables dnsmasq-full curl ca-bundle ipset ip-full iptables-mod-tproxy iptables-mod-extra ruby ruby-yaml kmod-tun kmod-inet-diag unzip luci-compat luci luci-base
curl -L --retry 2 https://api.github.com/repos/vernesong/OpenClash/releases/latest -o /tmp/openclash_version
[ -f "/tmp/openclash_version" ] && download_url=$(cat /tmp/openclash_version | jsonfilter -e '@.assets[*].browser_download_url' | grep '\.apk$') && curl -L --retry 2 "$download_url" -o /tmp/openclash.apk || echo "OpenClash last version get failed"
[ -f "/tmp/openclash.apk" ] && apk add -q --force-overwrite --clean-protected --allow-untrusted /tmp/openclash.apk || echo "OpenClash download failed"

若安装成功，重新进入Web管理界面，会出现Service->OpenClash菜单，点击进入后可以进行配置。通过Config Subscribe 导入配置文件下载地址，点击Config Manage进行配置文件信息查看以及更新。最后在Overview中可以启动OpenClash服务。

7.界面美化

通过命令行下载argon主题和argon配置插件：

wget https://github.com/jerrykuku/luci-theme-argon/releases/download/v2.4.7/luci-theme-argon-2.4.7-r1.apk
wget https://github.com/jerrykuku/luci-theme-argon/releases/download/v2.4.7/luci-app-argon-config-2.4.7-r1.apk

如果下载不成功，可以通过本地下载后通过scp命令上传到软路由。 最后运行安装命令。

apk add --allow-untrusted ./luci-theme-argon-2.4.7-r1.apk ./luci-app-argon-config-2.4.7-r1.apk

安装成功后，重新进入Web管理界面，点击System->System，选择Language and Style，在Theme中选择argon，保存并应用。

重新进入Web管理界面，进入System->Argon Config菜单，点击进入后可以在界面中进行主题设置和个性化配置。在Wallpaper source选择Build-in，通过页面底部上传自己喜欢的壁纸图片，即可修改。同时也可以通过本页面修改按钮颜色等参数。

8.其他设置

8.1.设置时区和主机名称

在Web管理界面中点击System->System，在General Settings中可以设置时区和主机名称。

8.2.Web页面添加终端管理

命令行运行：

apk add luci-i18n-ttyd-zh-cn

重新进入Web管理界面，将会出现Service->Terminal菜单，点击进入后可以在Web页面中直接使用终端命令行管理软路由。进入Config菜单，在Command一栏填修改为/bin/login -f root，保存并应用后即可使用Web管理界面进行命令行运行，不需要ssh。

8.3.温度显示

命令行运行：

wget --no-check-certificate -O /tmp/luci-app-temp-status-0.8.1-r1.apk https://github.com/gSpotx2f/packages-openwrt/raw/master/25.12/luci-app-temp-status-0.8.1-r1.apk
apk --allow-untrusted add /tmp/luci-app-temp-status-0.8.1-r1.apk
rm /tmp/luci-app-temp-status-0.8.1-r1.apk
service rpcd restart

安装好后重新进入Web管理界面，在Status->Overview中可以看到软路由的CPU以及硬盘的温度显示。

8.4.语言设置

在System->Software中点击update list更新软件源。filter中搜索chinese，找到luci-i18n-base-zh-cn，点击安装。System->System中 选择Language and Style 切换为中文。
